Query-time memory access

Hybrid Retrieval

输入与检索文本

retrieveStateCandidates(queryPlan, states, evidence, options) 接收 Query Planner 生成的 target、keywords、state_scopes、temporal_operator、evidence_facets 和选项，以及该问题当前可见的全部 State/Evidence。每条 State 的检索文本由 value + family + status + polarity 和其 evidence_ids 指向的 Evidence text 合并而成。

候选信号

信号匹配对象当前实现对候选的作用
词面Query Plan 的 keywords、target在 State 与关联 Evidence 的合并文本中做规范化后的直接包含匹配。命中 keyword_match 或 target_match，作为最高强度的直接召回信号。
alias药名、疾病、症状等医学同义词与中英文别名从 target、keywords 和选项扩展 alias，再与合并文本匹配。命中 medical_alias_match，召回没有复用问题原词的同义 State。
ngram未直接命中的 query term中文去空格和标点后计算字符 ngram 覆盖；英文计算 token 重合；阈值为 0.42。命中 lexical_ngram_match，补充近似表述候选。
scopefamily + priority匹配 Query Plan 的 State family；primary、secondary、support 产生不同权重。命中 scope_family_prior；scope 是软先验，不是过滤条件。
facetevidence_facets将 facet 拆成检索词并结合 State family 与内容判断；IG/MCD 还按关键 family 和 facet 做覆盖配额。命中 evidence_facet_match，在复杂题中保障客观值、症状、治疗反应、禁忌等维度。
EvidenceState 的 evidence_ids 与 Evidence 原文Evidence 原文参与匹配；共享 Evidence 的 sibling States 按 provenance component 轮转，并优先保留带来新 Evidence 的候选。避免同一 Evidence 产生的多个 State 占满预算；最终按 Evidence ID 去重组装原文。
Content Dedup Gate规范化内容、polarity 与 Evidence provenance候选评分后，将内容完全一致且来自同一 Evidence 集合的 State 合成一个查询时条目；持久化 State 不变。一个合并组只占一个候选名额；组内保留全部原始 State、state_id、family、version、time 与 Evidence。
versionsupersedes、version_chain、conflicts_with 与反向后继state_update 命中一个 State 后，扩展其历史、冲突和后继 State，并按 current/latest 时间语义排序。扩展项标记 version_chain_context，让当前状态与旧状态变化同时进入候选。

固定 Evidence Index Gate

阶段固定行为输出
索引每道题都建立 state ID、family、episode、Evidence ID、entity 与 version 索引；前端和 API 均没有关闭选项。只索引当前 query 可见的 State/Evidence，不接收 Gold、Judge metadata 或 reference key point。
第一遍先找 query 直接锚点，再沿 version、共享 Evidence 和相同实体关系扩展；同时保留原 Hybrid Retrieval 的词面、alias、ngram、scope、facet 与选项信号。带索引通道和可追溯 State ID 的候选。
覆盖补召回计算 coverage 的 required/covered/missing facets，为缺失 facet 做有界补检。typed Evidence chain、覆盖率、缺失 facet 与 second-pass State。
直通索引召回信号与 Hybrid Retrieval 合并后，继续执行 provenance 轮转、内容去重和题型安全上限。candidate_passthrough 上下文与完整 trace。

三个门

顺序门固定 State family 输入结构化输出约束
1Clinical Need & Safety主：CS + PE
辅：BC + LO + CP		risk level、red flags、contraindications、safe action set、forbidden actions、must escalate。最高优先级；升级处理与硬安全约束不能被后续门覆盖。
2Understanding & Clarification主：PA
辅：PE + CS + LO		belief facts、conflicts、missing information、clarification/verification/education targets，以及 ASK / VERIFY / EDUCATE / ANSWER。缺失信息直接读取固定 Evidence Index Gate 的 coverage，不用医学常识补造患者事实。
3Preference & Feasibility主：PA + BC
辅：CP + PE + LO		preferences、feasibility constraints、feasible/excluded options、personalized ranking、implementation plan。只能在第 1 门允许的安全集合内排序；must escalate 时停止常规偏好排序。
